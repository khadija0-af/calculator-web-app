# Calculator Web App 🧮

A simple and user-friendly calculator web application built as a web development project.

## ✨ Features

* Basic arithmetic operations
* Clean and simple interface
* Interactive calculator buttons
* Responsive layout

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📁 Project Structure

* `index.html` — Structure of the calculator
* `style.css` — Styling and layout
* `script.js` — Calculator functionality

## 🎯 Purpose

This project was created to practice front-end web development concepts, including HTML structure, CSS styling, and JavaScript functionality.
